# 长期信用分配的小对照

2026-09-22。局部机动实验正在按冻结源`3c9386d`执行；本项准备另一种机制，不覆盖其训练器或改变其中的优势计算。

## 具体问题与依据

信息对照中新增事实会改变value，但较少改变所查接敌状态的argmax动作；新局部动作已经被真实尝试，但终局MC信号仍会把整场后果带给很多不同操作。它不表示MC传播不了长期奖励，也不证明某次局部止损本来能赢。本项只检验旧value的时间差能否降低这种噪声。

用户授权的[Pro咨询第四轮](https://chatgpt.com/c/6ab1e596-5fc4-83ec-bda3-c2013c713800)读取了固定`3c9386d`，建议仅比较λ=1与.99。已核对[GAE原论文第5节](https://arxiv.org/html/1506.02438v6#S5)：GAE可以配合MC价值回归，优势使用更新前的value；减小λ在降低方差的同时会引入预测误差带来的偏差。这里不迁移训练框架，也不增加击杀/走位奖励。

在最近完成的一块on-policy主线local47采样中，每个地图/对手取repeat0，共24局。按局平均的value平方误差为0.183，可行动状态为0.179，同样24局的常数胜率预测为0.243；记录间隔均75 tick、最大末端间隔72 tick。这仅是开发数据上的实用检查，不是未见校准、优势准确性或GAE收益证明。

## 保持什么、只改什么

- 胜负效用继续W=1、L/U=0，E排除；γ=1，末端bootstrap为0。上限属于当前有限时域目标的未胜终局，不套用通用的超时bootstrap。
- MC臂保留原`ret-oldvalue`路径；GAE臂在每局内按时间倒序递推δ，再展平。中间即时奖励为0，只在最后转移给一次终局结果。强制KEEP参与递推和critic监督，仅在actor损失及优势归一化时排除。
- critic仍对广播的MC终局结果做回归，使用当前原有sigmoid/MSE/联合梯度裁剪；不把`A+V`换成critic目标。一批内优势固定，不使用本批更新后的value重新计算。
- `method`保持`ppo`，继承Adam；记录γ、λ和critic目标。旧模型缺省仍λ=1，已标记λ的模型续训时沿用，显式参数可覆盖。
- 只比较1和.99，不扫.95。75 tick约5游戏秒，.99对90秒后的残差仍保留约0.83权重；不把这个工作默认值说成已证最优。

回归覆盖λ=1逐行等价、W/L/U、多episode边界、强制KEEP、即时奖励仅一次，以及中间漏行/末端缺口拒绝。真实完整批次的数值对照、训练导出和完整局结果仍待执行。

## 准备的实验

局部菜单结果收取后固定一种菜单。每路线从同一checkpoint和Adam分叉MC/.99，各47/83两重复；首轮可共享同一checkpoint的on-policy采样，之后各自重新采样。主线/压力继续交替、轮内同池，保留未更新起点并用完整局比较。没有受控出生或快照分叉。

先跑有界比较，不把优势符号更合直觉、loss下降或value更乐观当作成功。特别检查是否更频繁回家/超时；value可能把脱离敌人视野错误判断为变好。若结果很小或退化，保留负结果并降低这个配方的优先级。
