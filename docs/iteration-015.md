## 第一轮结果和修正

`688456b` 的 12 局小筛：候选 3/6 胜、2 负、1 上限；0.1.14 为 4/6 胜、2 负。同池为 Supalosa、0.1.14 pressure、0.1.8 bastion，城市/短图各一局。不能晋升。

城市 Supalosa 上限局 `runs/iteration-015-screen-1/mp29u2.map/supalosa/0-committed-015` 原回放 360/360 快照匹配。GUI 实看 40:00，大量坦克堆在基地。原因是新成员加入重置战术等待、清空目标区触发返家、探索命令没有稳定后续目标。第二轮修正这些衔接：少数掉队者自行追赶、清场后就地继续搜索，并使用静态路线提示。临时回放已关闭。

第二轮 `4d69196` 地图输入变更：只在第 0 tick 读取原始地形字段、初始桥面高度与中立建筑轮廓，构建独立 ngraph；不读战斗方单位、当前全图资源或实时引擎路径缓存。这是赛前地图先验的新信息条件，旧版整包对照包含信息条件差异，不称为纯策略消融。初始化被显式限制为第 0 tick。动态敌情、工程师目标仍来自合法可见 API。

第二轮还接入可见收入建筑捕获任务、攻守共用的坦克目标选择和友军后方伤员轮换。后两者需要真实对局验证，几何条件与命令提交不等于战斗收益。该冻结提交沿用了 dev.1 显示版本，实验按提交和内容哈希区分；后续候选递增显示版本。
