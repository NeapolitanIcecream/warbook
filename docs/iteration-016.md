# 0.1.16：原生命令与矿区保护

2026-09-20，从 `v0.1.15` 开始。用户授权记录学习架构讨论，并完成三项规则行为后交付一版。[学习边界](learning-boundary.md) 已保存；本轮不开始学习训练。

## 验收与对照

- 原生命令：保持正在执行的同一动作；任务转换和真实失效才能必要重发。比较实际行为与完整局，不以命令越少越好作为评分。
- 矿车：己方受损和合法可见威胁触发返矿，原生 Dock 执行；在真实引擎核对传送、资金和恢复采矿。不得读取隐藏攻击者或私有敌情。
- 矿区：按正在作业的己方矿车选择区域，屏卫随转场更新；不跟着卸矿瞬时移动来回拉扯，不把远征军整组召回。
- 维持主线/压制共同更新，冻结两边和对手；短图/城市先筛查，随后四图对旧主线、旧压制、旧阵地和 Supalosa 完整比较。普通新局，非配对种子。
- 合理机制检查、完整回放核对、玩家入口开局/操作/结束/重开；保存失败候选。资产、回放、运行日志和本地配置继续只在忽略目录。
