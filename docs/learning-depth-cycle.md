## 为什么调整评测初始化

历史15,488局只用了8,526个不同的`gameId+gameTimestamp`来源。5,281局位于1,738个同源同图重复组，组内创建槽位对应的出生没有冲突；最终1,472局全部未换位。8个短引擎实例直接复现同秒随机源复用，另4个真实runner实例验证错开创建后来源各异。短机制局不计入完整局胜负。

共享来源不等于共享完整轨迹，也没有据此解释全部历史反转。新确认赛在相同协议下重评起点和候选，明确轮换创建/执行槽位；这仍不是固定地图出生或精确配对。初始化只串行创建，对局继续并行。训练采样不使用节拍，但与确认赛分阶段执行，避免两阶段再共享创建秒。
