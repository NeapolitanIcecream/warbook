# 当前主力接敌信息：同 checkpoint 对照

2026-09-22，用户已授权继续研究和实验。分支`codex/contact-information`，玩家稳定版仍0.1.16。依据[已复现的编码缺口](rl-bottleneck-review.md)，本轮首先检验信息缺失，不混入动作扩权、奖励变化或战术规则改善。

## 实验定义

- `operation-contact-v1`保留原212维历史与事实，在其后追加5个当前事实，形成217维global；候选仍48维、最多75项。网络仍两层128宽，共95,234参数。
- 五项为实际主力成员的最近可见地面威胁距离（32格截断）、6/12格内可见敌装甲数量、受到敌武器射程覆盖的比例、己方武器射程内有可见威胁的比例。使用既有合法观察及三维射程距离；范围覆盖只是几何估计，不冒充冷却、视线或真实输出。行军增援、预备和独立矿区守备不进入主力集合；撤回订单使用实际撤回成员。
- 两臂网络同形：`zero`将五项置零，`local`读取实际值；actor与critic同时接入。旧global与candidate权重按语义列迁移，新列和Adam矩置零，保留Adam步数。模型中必须显式标记输入模式，避免训练/评测混用。
- 主线从整夜主线operation83末次`f97f9923…`开始；压力从压力operation83末次`3844e6e…`开始。每路线两臂、各47/83两个独立随机重复，均从同一对应路线checkpoint及Adam状态分叉。它们不是不同BC起点。
- 每个模型先3轮、每轮192场新完整对局，共576场；两路线交替推进。固定部分为0.1.16主线、0.1.16压力、Supalosa、对方路线保留的强窄权限模型；另加入对方路线两臂的当轮冻结模型，重复索引按轮交替选择，不用逐轮小样本胜场淘汰。两臂在同一路线/轮次使用相同对手池。初始两臂策略相同，不能当作两个独立策略家族。
- 3轮共4,608场RL采样。最终每路线纳入4个学习端点、未更新起点、旧强窄权限与规则基线，每模型192场同池比较，合计2,688场；正式预算7,296场。均为已见四图，交换创建槽但出生不配对。先取得这批结果，再决定确认或接敌动作实验，不以编码可分/新增权重变化替代强度。

成功标准是：合法输入无间接泄漏、迁移与真实执行正确，且有完整局证据说明新增信息是否改变接敌决策并改善能力。阴性结果仍需检查实际利用率/失败回放以区分训练不足与动作无法利用信息，不原样无限续训。

## 实施与验收

已增加近敌/远敌编码反例、旧历史/候选保留、增援排除、三维射程与撤回成员检查；174项Node检查和类型检查通过。本机Python检查19通过，PyTorch迁移检查随后在现成CPU训练服务器通过，涵盖初始概率及保留Adam历史后的下一步更新一致性。

`7ee355b`两路线各一局真实影子比较，共16,758次指令零差异，均正常结束。`d77a686`完整流程预检28局全部正常、0错误，走通四份初始化迁移/概率校验、两路线两臂各一份PPO、冻结新对手和最终比较；两份local模型的新输入权重确实变化，两份zero始终为零。此预检只有每臂两局采样和一个epoch，不用于强度判断。正式批次前仅补全迁移后的网络维度元数据和回放中的输入模式标识。

原始资源、配置、模型、Adam状态、数据及回放继续放在忽略目录/服务器私有目录。长任务独立于笔记本运行，复用批次压缩和空间预算；中断尝试单独保存，不能追加到旧episode。

## 完整结果：本预算没有显示新增信息的稳定收益

冻结`884428b`实际完成7,296局：7,012正常终局、283 tick上限、1双方败北未决，0程序错误。24份PPO训练产物及逐局角色、模型SHA、源码、终局汇总复核一致；每模型确实完成3次更新、576新局。全部地图均已见，出生没有配对。以下每份192局，W/L/U；不同路线面对的适应对手不同。

| 路线 | 模型 | W/L/U |
|---|---|---|
| 主线 | zero 47 / 83 | 122/63/7；115/69/8 |
| 主线 | local 47 / 83 | 120/65/7；117/67/8 |
| 主线 | 未更新operation / 强窄权限 / 规则0.1.16 | 127/56/9；126/55/11；103/85/4 |

主线两臂合计相同，压力local比zero少12/384胜。不能据此宣称输入修复提高了实力，也不能证明当前空间已经学满；仅576局/模型是一次有限比较。各模型都胜过同池规则的原始胜场，但已有起点本身就更强，不能全部归于本轮RL。

从每份local最终模型的24个开发对局各取最多5个接敌状态，保持其他输入/候选固定，只把5个当前接敌字段换成“无近处威胁”向量。四份各120样本中，最大概率动作分别只变化2、0、2、2次；平均动作分布总变差约0.0039、0.0045、0.0067、0.0069，平均value变化0.025、0.022、0.030、0.034。这个输入干预显示信息进入了网络、对value影响较明显，但很少改变这些样本的贪心命令；不是反事实胜率或总体使用率估计。

完整审计与输入检查在`work/contact-information/harvest/`，原始资料仍在服务器。下一步优先保留强起点，提供真正能改变局部运动的选项，并同步编码落点威胁；不把原样追加训练当作已解决。
