# 当前主力接敌信息：同 checkpoint 对照

2026-09-22，用户已授权继续研究和实验。分支`codex/contact-information`，玩家稳定版仍0.1.16。依据[已复现的编码缺口](rl-bottleneck-review.md)，本轮首先检验信息缺失，不混入动作扩权、奖励变化或战术规则改善。

## 实验定义

- `operation-contact-v1`保留原212维历史与事实，在其后追加5个当前事实，形成217维global；候选仍48维、最多75项。网络仍两层128宽，共95,234参数。
- 五项为实际主力成员的最近可见地面威胁距离（32格截断）、6/12格内可见敌装甲数量、受到敌武器射程覆盖的比例、己方武器射程内有可见威胁的比例。使用既有合法观察及三维射程距离；范围覆盖只是几何估计，不冒充冷却、视线或真实输出。行军增援、预备和独立矿区守备不进入主力集合；撤回订单使用实际撤回成员。
- 两臂网络同形：`zero`将五项置零，`local`读取实际值；actor与critic同时接入。旧global与candidate权重按语义列迁移，新列和Adam矩置零，保留Adam步数。模型中必须显式标记输入模式，避免训练/评测混用。
- 主线从整夜主线operation83末次`f97f9923…`开始；压力从压力operation83末次`3844e6e…`开始。每路线两臂、各47/83两个独立随机重复，均从同一对应路线checkpoint及Adam状态分叉。它们不是不同BC起点。
- 每个模型先3轮、每轮192场新完整对局，共576场；两路线交替推进。固定部分为0.1.16主线、0.1.16压力、Supalosa、对方路线保留的强窄权限模型；另加入对方路线两臂的当轮冻结模型，重复索引按轮交替选择，不用逐轮小样本胜场淘汰。两臂在同一路线/轮次使用相同对手池。初始两臂策略相同，不能当作两个独立策略家族。
- 3轮共4,608场RL采样。最终每路线纳入4个学习端点、未更新起点、旧强窄权限与规则基线，每模型192场同池比较，合计2,688场；正式预算7,296场。均为已见四图，交换创建槽但出生不配对。先取得这批结果，再决定确认或接敌动作实验，不以编码可分/新增权重变化替代强度。

成功标准是：合法输入无间接泄漏、迁移与真实执行正确，且有完整局证据说明新增信息是否改变接敌决策并改善能力。阴性结果仍需检查实际利用率/失败回放以区分训练不足与动作无法利用信息，不原样无限续训。
