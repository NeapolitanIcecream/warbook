## 第一项候选：bastion

初始假设与可检验行为：

- 步兵始终归属基地守备任务，到岗后 E1 部署；坦克单独集结。岗位来自己方基地、公开起点和首次合法可见近处敌军，不访问隐藏状态。
- 沿用 0.1.7 的经济目标和矿车承诺记账，车辆工厂建成后另买一座碉堡/哨戒炮，费用来自正常收入。现有已探索范围的建筑放置入口保持不变。
- 反击由八辆已出厂、位于基地集结范围内的坦克触发；15000 tick 后可由四辆触发。主力成员持续保留，剩两辆坦克时回到集结阶段；后续增援先积累四辆，成为独立汇合任务。
- 第一轮出击仍使用原局部作战控制，尚未声称能持续保持行军队形、轮换承伤或实现 T 优；防守组合与这些后续战术分开。

这些数字是首轮候选参数，不是玩家给定规则或已验证的最佳值。主要风险是岗位不在实际交火方向、步兵反复部署/移动、工事挤占补兵、反击过晚或增援无法汇合。需要从真实行为和完整局决定下一步。

## 为实际分工补齐的控制边界

在原主力任务旁增加有明确单位归属的附加作战任务；任务 ID、修订、效果反馈及旧命令拒绝覆盖全部任务。守备需要原生 Stop，加入这个动作，不能用不断下发 AttackMove 冒充原地防守。不同任务间转交时清理该单位的战术命令缓存，避免旧“已下令”状态阻止新的停止/出发指令。

原 `factory-exit` 保持默认算法；先做少量同观察指令比较确认接口扩展没有改变旧策略。新策略不要求与旧策略输出相同。

初版来源 `382951b`。44 项测试通过，原 factory-exit 的两场完整影子比较正常结束，7,694 次指令无差异。bastion 初始四场全部正常败北，不能将部署和工事出现等同于有效新对手。

实际四场都在 tick 3552 出现碉堡，最多六名大兵部署；Para、Vulcan2 和坦克炮都有击毁敌方坦克的记录。小镇 0 号局的原回放、稀疏快照和终局核对通过：守方挡住第一波，第一辆坦克到 13939 才损失；但 12000 时矿车在 (35–36,75–78) 受袭，主力留在 (26–35,87–95)。13500 时七辆坦克仍在，矿车已为零。固定岗位和过晚出击没有保护经济，不能据此否定玩家指出的防守优势。

## 主线编组实验与负结果

1. `4f107e7` / `cohort`：保留守家步兵、反击主力和四车增援批次，尝试共享短途移动、途中收拢和接敌后的移动射击。`cohort-screen` 候选 0/8（5 正常负、3 上限），同批 0.1.7 为 4/8，八局均正常。上限仍 Started、无 turn-manager 错误；两个终态分别有 53、60 辆坦克，却未能完成攻坚。该实现会将援军不断并入单一大队，中心/距离控制不能可靠处理其规模与地形，不能把“能移动开火”升级为已具备集群战术。
2. `63ec881` / `cohort-local`：固定编组战略，恢复原局部战斗控制。`cohort-local-screen` 两方各 6/8，全部正常；新候选对阵地反击 4/4，但短图对 Supalosa 0/2，旧主线该格 2/2。没有晋升主线。
3. `648b888` / `cohort-local`：推迟经济扩張直到首批六车实际发起任务，另外修复全灭后的成员回收。`cohort-budget-screen` 候选 3/8、旧主线 6/8，全部正常。该方向也未显示稳定收益，不继续微调相同预算假设。

失败的单一大队移动实现及其特定测试已从当前运行代码移除，Git 和完整实验仍可追溯至 `4f107e7`。`cohort-local` 仅保留为研究模式，不用于玩家默认对手。后续需要从有限小队、射击窗口、侦察和实际交战反例出发；不能用更密的命令或更大的聚拢半径代替战术。

本轮结构检查发现主力在一次观察间隔内全灭时，原过滤顺序会漏掉“重整”分支，让未汇合援军滞留在旧任务中；已以保留过滤前状态修复，并增加全灭/援军回收测试。先行包 47 项测试通过（收尾权限修正后为 48 项）。未发现需要通用调度平台的阻碍，未做不等价的性能提升声明。

## 部署与工事的贡献复查

[bastion-support-ablation.json](../experiments/bastion-support-ablation.json) 固定 32 次，两图对 0.1.7，各组合八次，全部正常结束：完整组合 4/8，取消部署 5/8，两者都取消 6/8，只取消工事 7/8。

不能将这一排序解释为“不要部署/不要工事”或“已经证明它们增加胜率”。短图四个组合都是出生位 0 全胜、出生位 1 全负，但完整组合在出生位 1 有三场，只取消工事的组合仅有一场；小镇覆盖也不相同。取消工事还会腾出资金、改变部队驻防锚点。当前样本未分离这些影响，不自动重加权，不把移除后的结果藏掉。

实际 Para / Vulcan2 交火与击毁证据说明能力被使用，整套候选也确实能克制旧主线；**各组成部分的独立收益仍未确认**。保持所验证的完整组合为实验挑战者，其他消融版本作为冻结研究记录，不扩成四个“独立策略家族”。后续优先解释短图出生位 1 的防线覆盖和接敌问题，不继续盲调同一套门槛。
